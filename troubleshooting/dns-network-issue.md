# DNS / Network Connection Troubleshooting

## Problem
A laptop was having a network/internet connection issue.

## What I checked
- Pressed `Windows + R` to open the Run dialog
- Typed `scpa.cpl`
- Opened Network Connections
- Opened the network adapter Properties
- Checked IPv4 settings
- Checked the IP configuration
- IP address observed: `10.50.80.90`
- Checked the DNS settings

## What I changed
I changed the DNS server settings.

## Result
the browser was able to access the required website

## What I learned
- How to use `Windows + R` to access Windows tools
- How to access network adapter properties
- Where IPv4 and DNS settings are located
- How DNS can affect internet connectivity
- Basic network troubleshooting

## Commands / Tools
- Windows Run (`Windows + R`)
- `ncpa.cpl`
- Network Connections
- IPv4 Properties
- DNS settings
