# TechCare ICT Help Desk

A simple, responsive help desk website for ICT support requests.

## Pages

- `index.html` — Home page with an overview of TechCare services.
- `report.html` — Form for reporting a technical problem.

## Run locally

Open `index.html` in a web browser. Use the navigation or the support buttons to open the report form.

The form checks required fields in the browser and displays a confirmation when submitted. This demo does not send or save reports to a server.

## Project files

- `style.css` — Shared page styling and responsive layout.
- `script.js` — Report form submission behavior.
